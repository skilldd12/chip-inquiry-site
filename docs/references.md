# 参考源查阅记录

本文件记录阶段 A 查阅过的参考站点、skill 与文档，以及**实际借用了什么、明确没借什么、哪些没读到**。
所有判断基于抓取到的文本层 + 可核对的官方文档条目；对依赖视频/WebGL 的实现细节，凡未亲眼验证的一律标注「未能确认」，不编造结论。

## 2. 技术文档查阅

| 文档 | 关键结论（已按原文核对） | 在项目里的落地 |
| --- | --- | --- |
| GSAP ScrollTrigger 文档 | `pin` 只允许一个固定元素；**不要对被固定元素本身做动画**，否则测量失准，动画要作用在其子元素上；`scrub: 数字` 表示播放头追赶滚动的秒数；`end` 是静态计算值，动画改变布局后需 `ScrollTrigger.refresh()`；`ScrollTrigger.matchMedia()` 已废弃，改用 `gsap.matchMedia()`；祖先带 `transform` / `will-change` 会破坏 `position: fixed` | hero 用 `pin: stage`，而所有位移/缩放都作用在 `layer1..3` 这些子元素上；`scrub` 用数字（桌面 0.7）而非 `true`；断点切换用 `gsap.matchMedia()`，并在 cleanup 里 `revert()` |
| Next.js App Router 文档 | `params` / `searchParams` 是 Promise；SSG 需要 `generateStaticParams` | 所有 `[locale]` 页面按此写，构建产物中三语页面全部静态化 |
| Node `node:sqlite` | `DatabaseSync` 为同步 API，实验特性但可用 | 作为唯一持久层，省掉原生编译步骤（Windows 上尤其重要） |
| ExcelJS 文档 | 支持流式写入与公式识别 | 模板生成、错误行工作簿；读取时**拒绝**公式单元格 |

## 3. 没有做到 / 没有验证的部分（如实记录）

1. **Apple 与 Teenage Engineering 的图片构图、视频节奏**：抓取只拿到文本层，无法确认其摄影机位与滚动实现细节。本项目首屏构图是独立设计，不是对这两站的还原。
2. **OCEAN 片段未取得**：仅借结构，未看原片；因此不声称「还原了那种转场」。
3. **品牌官方标识**：11 个品牌没有可合法取得的矢量标识，页面上用文字字标占位（见 `docs/asset-gaps.md`），**没有**生成或仿制商标。
4. **真实摄影**：首屏三帧与仓储图为生成图，属占位素材，上线前必须替换（见 `docs/asset-gaps.md` 的替换清单）。
5. **`prefers-reduced-motion` 下的 Chrome 渲染验证**只在 Chromium 内用媒体特性模拟完成，未在 Safari / Firefox 实测。
