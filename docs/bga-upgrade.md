# BGA 及内容升级交付

本机预览：http://localhost:4311/zh 。实际项目目录为当前项目根目录。

- 首屏为 NXP 风格塑封 BGA 实时模型，包含底部焊球、鼠标视差和滚动视角变化；手机端取消固定滚动，减少动态设置及 WebGL 异常使用静态海报。
- 每种语言 41 个公开页面地址，涵盖产品分类、品牌、采购服务、行业、仓储、品质、公司、联系、FAQ、资源与法律页面。中英俄共 123 个地址。

- 现有 24 个品牌 LOGO 保留；型号、品牌、类别、服务和行业可传入询价表单，BOM 模板位于 public/templates/bom-template.csv。
- /admin/editorial 支持图片上传、三语标题说明与品牌/类别关联；保存后通过 revalidatePath 更新预生成页面。
- 本机正式模式会话及 IP 哈希密钥保存在 .env.production.local，已随机生成；不要公开或上传该文件。管理员账号及询价数据保持原样。
