Part numbers & packages

Why the ordering-code suffix matters

A suffix can distinguish package, grade or shipment format. Decode it using the ordering information for that specific device.

01 / Family, base device and ordering code02 / Do not reuse suffix rules across brands03 / The same package name is not enough

01 / Family, base device and ordering code

A family name helps locate products; a base device identifies a design; the complete orderable code identifies the purchasing variant. Copy the approved BOM or manufacturer code in full rather than reconstructing missing suffixes from memory.

02 / Do not reuse suffix rules across brands

Coding conventions vary by manufacturer and family. Use the relevant datasheet revision, ordering table and package drawing to verify package, temperature, speed, precision and packing. If uncertain, send the original code and documentation link.

03 / The same package name is not enough

Even with the same package abbreviation, check pin count, pitch, dimensions, exposed pad and pinout. Shipping format such as reel or tray is a separate field from device package. For split packs, separately agree quantity, label information and protective packaging.
