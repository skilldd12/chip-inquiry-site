型号与封装

为什么不能省略型号后缀？

一个后缀可能区分封装、等级或包装。解释规则以该器件的原厂订货资料为准。

01 / 系列名、基本型号与订货号02 / 后缀含义不可跨品牌套用03 / 同封装仍需核对引脚与尺寸

01 / 系列名、基本型号与订货号

系列名帮助寻找产品，基本型号用于识别器件方向，完整订货代码用于确定具体可采购版本。询价尽量照录已批准 BOM 或原厂资料中的完整代码，不靠记忆补齐缺失后缀。

02 / 后缀含义不可跨品牌套用

不同厂商和不同系列的编码方式可能不同。对照对应版本的数据手册、订货表和封装图，分别核实封装、温度、速度、精度及包装方式。无法判断时提交原始代码与资料链接。

03 / 同封装仍需核对引脚与尺寸

封装简称相同，也应核对引脚数、间距、外形尺寸、散热焊盘和引脚定义。卷带/料盘等供货包装与器件封装是两个字段；拆零供货时另行确认数量、标签与防护方式。
