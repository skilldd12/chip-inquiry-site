日期码、批次与包装记录怎样看？

日期码是核对信息之一，不能单独证明器件状态、真伪或电性能。

01 / 先确定字段是什么02 / 把要求写成可执行条件03 / 日期码与保存状态分开评估

01 / 先确定字段是什么

标签可能同时包含订货号、批号、日期码、封装/测试信息及包装日期。不同厂商规则不同；包装或重新密封日期不应自动当作生产日期。对照原厂标签说明，无法解读时保留照片并询问。

02 / 把要求写成可执行条件

项目若限制日期范围、单一批次或禁止混批，应在询价时明确，而不是下单后补充。供应回复应对应数量和包装单位，说明是否可能分属不同批次，以及可提供哪些标签或记录。

03 / 日期码与保存状态分开评估

较早日期不必然意味着失效，较新日期也不自动保证适用。应结合原厂指引、包装完好程度、存储记录与项目要求评估。有焊接性、可靠性或真伪疑问时，另行约定适合的检测范围。
